
# Guest Mode

`keypad_node.py` 안의 게스트 입력 처리 로직입니다. 가족 프로필(A/B/C)에 없는 손님이 키를 직접 입력해서 시트를 조절할 수 있게 합니다.

## 진입 방식 2가지

| 방식 | 트리거 | 동작 |
|---|---|---|
| 수동 입력 | D 키 짧게 누름 | LCD에 `Guest Mode / Enter H: _` 표시, 숫자 키패드로 직접 입력 |
| 자동 측정 | D 키 3초 이상 롱프레스 | 초음파 센서로 자동 신장 추정 (별도 문서: `ultrasonic_filter.md` 참고) |

## 수동 입력 상태 흐름

```
D(짧게) → 게스트 모드 진입 (입력 버퍼 초기화)
  ├─ 숫자(0~9) → 버퍼에 추가, LCD 갱신 (최대 6자리)
  ├─ '.'
  │    ├─ 버퍼가 비어있으면 → 게스트 모드 탈출 + 리셋 (허리만)
  │    └─ 버퍼에 값이 있으면 → 소수점 추가 (중복 방지)
  ├─ E → 버퍼 값 파싱 후 범위(130~185cm) 검증
  │    ├─ 범위 내 → 적용(/body_data 발행) 후 게스트 모드 자동 종료
  │    └─ 범위 밖 / 파싱 실패 → 에러 메시지 표시 후 버퍼만 초기화 (게스트 모드 유지)
  └─ D(짧게) → 게스트 모드 취소, 입력 버퍼 폐기
```

## 안전장치 — 게스트 모드 오진입 자동 복구

키패드 배선 노이즈로 인해 의도치 않게 D가 눌려 게스트 모드로 잘못 진입하는 경우가 있었습니다(연장 케이블 접촉 불량 이슈). 이 상태에서 A/B/C 같은 프로필 키를 누르면 원래는 무시되어 사용자가 갇힌 것처럼 느껴지는 문제가 있었는데, 다음 안전장치로 해결했습니다:

> 게스트 모드 중에 프로필 키(A/B/C)가 눌리면, "노이즈로 잘못 들어왔다"고 판단하여 게스트 모드를 자동으로 취소하고 해당 프로필을 즉시 적용합니다.

이전에 시도했던 "일정 시간(15초) 입력 없으면 자동 종료" 방식은, 사용자가 신중하게 숫자를 입력하는 도중에도 타임아웃될 위험이 있어 폐기하고 위 방식으로 대체했습니다.
