# 테스트 및 트러블슈팅 로그

개발 과정에서 실제로 겪고 해결한 문제들을 시간 순서와 무관하게 주제별로 정리했습니다. 심사 서류의 "개발 중 발생한 장애요인과 해결방안" 항목의 근거 자료로 활용합니다.

---

## 하드웨어

### 1. 스텝모터(NEMA17+DRV8825) 반복 소손
- **증상**: 확장보드 발연, GND/VMOT 점퍼선 용융 2회
- **원인**: 확정 못함(전류제한 미설정 추정)
- **해결**: 다이나믹셀 XL430 + U2D2로 전면 교체 (전류 제한 내장)

### 2. 스텝모터 구동 시 라즈베리파이 저전압 증상
- **증상**: 간헐적 USB 끊김, `Undervoltage detected!` — 스텝모터(NEMA17+DRV8825) 구동 중에만 발생
- **원인**: PD 어댑터 자체의 비호환 문제가 아니었음. 같은 어댑터(PD/고정 5V 겸용)가 이전·이후 모두 정상 동작 — 스텝모터 구동 시 전류 소모가 커지면서 공유 전원 계통 전압이 흔들린 것으로 추정
- **해결**: 스텝모터를 다이나믹셀로 교체한 뒤 증상이 완전히 사라짐. 별도의 전원 어댑터 교체는 필요 없었음 (원래 어댑터 그대로 사용 중)

### 3. 벨트 장기 미사용 후 토크 꺼짐
- **증상**: 여러 날 방치 후 재시작 시 홈 복귀 로그는 정상 출력되나 실제로 벨트가 움직이지 않음
- **원인**: 노드 종료(`destroy_node`) 시 토크가 꺼진 채로 유지됨
- **해결**: 재시작 전 토크 활성화 확인 절차 추가

## 소프트웨어 / 캘리브레이션

### 4. 벨트 tick-to-mm 비율이 비선형처럼 보임
- **증상**: 동일 틱 명령인데 실측 이동거리가 매번 다르게 나옴 (릴 슬립으로 오판)
- **원인**: 테스트 스크립트가 고정 관찰시간(4~6초) 후 목표 도달 전 강제로 토크를 끊음 — 하드웨어가 아니라 테스트 도구 자체의 결함
- **해결**: 목표 도착까지 대기(포지션 스톨 감지)하는 방식으로 스크립트 재작성
- **교훈**: 물리적 원인을 추정하기 전에 자체 코드/스크립트의 한계부터 배제할 것

### 5. USB 포트 번호(`/dev/ttyUSB0/1/2`) 유동성
- **증상**: 재연결·재부팅마다 포트 번호가 바뀌어 연결 실패 반복
- **해결**: `udev` 규칙(USB Vendor/Product ID + 시리얼 번호)으로 `/dev/arduino_linear`, `/dev/belt_u2d2` 고정

### 6. 리니어 액추에이터 물리적 배치 스왑
- **증상**: 150mm 위치 액추에이터가 실제로는 Arduino 모터 채널 2에, 320mm 위치가 채널 1에 연결됨(조립 실수)
- **해결**: 재배선 대신 `MOTOR_MAP = [2, 1, 3, 4, 5]`로 소프트웨어에서 보정

### 7. 벨트 홈 위치 드리프트
- **증상**: 디버깅 중 수동으로 벨트를 옮긴 뒤, 다음 명령에서 예상 밖 위치로 이동
- **원인**: 저장된 `belt_home.json` 기준값이 실제 물리적 홈과 어긋남
- **해결**: 손으로 재정렬 후 현재 raw 인코더 위치를 `belt_home.json`에 재기록하는 절차 확립

### 8. 동시 명령 경합(Race Condition)
- **증상**: 같은 프로필 버튼(예: B)을 연타하면 벨트가 매번 다른 위치로 이동
- **원인**: 매 입력마다 새 스레드가 동일한 Dynamixel `GroupSyncWrite` 객체에 동시 접근
- **해결**: `threading.Lock`으로 벨트 이동 명령 순차 실행 보장

### 9. 키패드 연장 케이블 유령 입력
- **증상**: 시작하자마자 D키가 저절로 눌린 것으로 인식, 특정 열/행(A/B/C/D 등)만 간헐적 오작동
- **원인**: 연장 케이블 커넥터 접촉 불량 (Row HIGH 시 여러 Col이 무작위로 동시 감지됨을 확인)
- **상태**: **진행중 대응** — 하드웨어(커넥터 고정)만으로 완전히 해결되지 않아, 소프트웨어로 다중 방어선 구축
  - 디바운스 4연속(200ms) 판정
  - 여러 열 동시 감지 시 유령 신호로 간주하고 무시
  - 부팅 후 1.5초간 키 입력 무시(전원 노이즈 구간 회피)
  - 게스트 모드 오진입 시 프로필 키 입력으로 자동 복구 (`guest_mode.md` 참고)
- **남은 과제**: 커넥터 납땜 고정 또는 케이블 교체로 근본 해결 필요

## 검증 방법 메모

### 벨트 캘리브레이션 검증
알려진 높이의 물체를 방석 위 특정 지점에 놓고 측정값과 비교하는 방식으로 `BELT_TICKS_PER_MM`, `BELT_CALIBRATION_OFFSET_MM` 상수를 실측 검증했습니다.

### 초음파 센서 시연 거리표
실제 사람이 2:1 축소 모형에 앉을 수 없으므로, 목표 키(cm)별로 손/물체를 놓아야 할 센서-대상 거리(mm)를 미리 계산해두고 시연에 사용합니다.

| 목표 키(cm) | 센서-대상 거리(mm) |
|---|---|
| 130 | 약 198 |
| 150 | 약 155 |
| 170 | 약 112 |
| 178 | 약 95 |
| 185 | 약 80 |

계산식은 `Seat_Control_Algorithm.md` 4절 참고.
