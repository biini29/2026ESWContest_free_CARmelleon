
## 1. 전체 구조 개요

- 2:1 축소 모형인 이유, 실물 대비 스케일 적용 방식 (간단히 1~2문단)
- 전체 조립 렌더링 이미지 1장 (`![전체 조립도](./전체조립도.png)`)

## 2. 등받이(백레스트) 구조

- 리니어 액추에이터 5개 배치 방식 — 어떤 프레임/레일에 고정되는지
- 액추에이터 간격(150/320/490/660/830mm)이 실제 구조물에서 어떻게 구현되는지
- `Linear Moter Lumber Structure` 폴더 내용과 연결되는 설명

| 항목 | 값 |
|---|---|
| 프레임 재질 | (채워주세요) |
| 액추에이터 고정 방식 | (채워주세요) |
| 등받이 곡면 재질(천+솜 등) | (채워주세요) |

## 3. 안전벨트 릴/가이드레일 구조

- 다이나믹셀 2개가 벨트를 감아올리는 릴 메커니즘 설명
- 릴 지름, 벨트(끈) 두께/재질
- 가이드레일이 있다면 그 역할

## 4. 헤드레스트 자리 — 초음파센서 ㄱ자 브라켓

- 3D 프린트로 제작한 브라켓 설계 의도
- 정확한 치수 (바닥 585mm + 브라켓 60mm → 방석 기준 570mm, `Seat_Control_Algorithm.md` 4절 참고)
- 브라켓 STL/도면 링크

## 6. 설계 시 고려한 제약사항

- 2:1 스케일로 인한 제약 (예: 실물 그대로 축소했을 때 발생하는 문제와 해결)
- 전시 부스 규격(2m×2m) 안에 들어가는지
- 운반/조립 관련 고려사항
