# Smart Seat System Pin Map

## 1. 전체 시스템 구성

```text
                    Raspberry Pi
                         │
                         │ USB
                         ▼
                   Arduino Mega
                         │
          ┌──────────────┼──────────────┐
          │              │              │
          ▼              ▼              ▼
       L298N #1       L298N #2       L298N #3
       모터 1, 2      모터 3, 4        모터 5
          │              │              │
          ▼              ▼              ▼
       확장보드 1      확장보드 2      확장보드 3
          │              │              │
       모터 1, 2      모터 3, 4        모터 5
```

# 2. Raspberry Pi → Arduino Mega

| 출발지              | 목적지              | 연결 방법   | 역할               |
| ---------------- | ---------------- | ------- | ---------------- |
| Raspberry Pi USB | Arduino Mega USB | USB 케이블 | ROS2 명령 및 데이터 통신 |

### 통신 구조

```text
Raspberry Pi
    │
    │ USB Serial
    ▼
Arduino Mega
    │
    ▼
L298N 모터 제어
```

> Raspberry Pi가 ROS2에서 모터 명령을 생성하고 Arduino Mega가 해당 명령을 받아 L298N을 제어한다.

| 모터   | Arduino Mega | L298N #1 | 기능    |

| 모터 1 |          D22 | IN1      | 방향 제어 |
| 모터 1 |          D23 | IN2      | 방향 제어 |
| 모터 2 |           D3 | ENB      | 속도 제어 |
| 모터 2 |          D24 | IN3      | 방향 제어 |
| 모터 2 |          D25 | IN4      | 방향 제어 |

```text
Arduino Mega                 L298N #1
─────────────────────────────────────

D22    ────────────────────→ IN1
D23    ────────────────────→ IN2

D3     ────────────────────→ ENB
D24    ────────────────────→ IN3
D25    ────────────────────→ IN4
```

# 7. L298N 전원 연결

12V SMPS를 모터 구동 전원으로 사용한다.

```text
                 12V SMPS
                 ┌───────┐
                 │ +V COM│
                 └─┬───┬─┘
                   │   │
          ┌────────┘   └────────┐
          ▼                     ▼
      L298N #1              L298N #2
          │                     │
          └────────┬────────────┘
                   │
                   ▼
               L298N #3
```

### 전원

| 출발지        | 목적지                | 역할     |
| ---------- | ------------------ | ------ |
| SMPS `+V`  | L298N #1 `12V/VCC` | 모터 전원  |
| SMPS `COM` | L298N #1 `GND`     | 전원 GND |
| SMPS `+V`  | L298N #2 `12V/VCC` | 모터 전원  |
| SMPS `COM` | L298N #2 `GND`     | 전원 GND |
| SMPS `+V`  | L298N #3 `12V/VCC` | 모터 전원  |
| SMPS `COM` | L298N #3 `GND`     | 전원 GND |

> L298N 모터 전원은 Arduino Mega의 5V 핀에서 공급하지 않는다.

---

# 8. Arduino Mega ↔ L298N GND

Arduino와 L298N은 **GND 기준을 공유해야 한다.**

```text
Arduino Mega GND
       │
       ├────────→ L298N #1 GND
       │
       ├────────→ L298N #2 GND
       │
       └────────→ L298N #3 GND
```

# 11. 최종 시스템 구조

```text
                    ┌─────────────────┐
                    │   Raspberry Pi   │
                    │      ROS2        │
                    └────────┬────────┘
                             │
                         USB Serial
                             │
                             ▼
                    ┌─────────────────┐
                    │   Arduino Mega   │
                    └────────┬────────┘
                             │
          ┌──────────────────┼──────────────────┐
          │                  │                  │
          ▼                  ▼                  ▼
     ┌──────────┐       ┌──────────┐       ┌──────────┐
     │ L298N #1 │       │ L298N #2 │       │ L298N #3 │
     │ Motor 1  │       │ Motor 3  │       │ Motor 5  │
     │ Motor 2  │       │ Motor 4  │       │          │
     └────┬─────┘       └────┬─────┘       └────┬─────┘
          │                  │                  │
          ▼                  ▼                  ▼
      확장보드 1          확장보드 2          확장보드 3
          │                  │                  │
       ┌──┴──┐            ┌──┴──┐              │
       ▼     ▼            ▼     ▼              ▼
     모터1  모터2       모터3  모터4          모터5

                    ▲
                    │
                12V SMPS
```

## 주의사항

* Arduino Mega와 L298N의 `GND`는 공통으로 연결한다.
* 모터 전원은 12V SMPS에서 공급한다.
* Arduino 5V로 모터를 구동하지 않는다.
* L298N #3의 B채널(`ENB`, `IN3`, `IN4`)은 사용하지 않는다.
* 모터 방향이 반대로 움직이면 해당 모터의 `IN1/IN2` 논리를 반대로 설정하거나 모터 연결 극성을 확인한다.
