# 전원 계통도

## 1. 전원 시스템 구성

스마트 시트 시스템은 **제어 계통**과 **모터 구동 계통**의 전원을 분리하여 구성한다.

* Raspberry Pi는 별도의 **12V/5V 겸용 어댑터를 5V로 설정**하여 전원을 공급한다.
* Arduino Mega는 **Raspberry Pi USB를 통해 5V 로직 전원**을 공급받는다.
* L298N 모터 드라이버 3개와 U2D2 Power Hub는 **12V SMPS**를 통해 전원을 공급받는다.
* 리니어 모터 5개는 L298N 모터 드라이버를 통해 구동된다.
* Raspberry Pi 전원 계통과 모터 구동 전원 계통은 **독립적으로 구성**된다.
* 본 시스템에서는 **Buck Converter를 사용하지 않는다.**

---

## 2. 전체 전원 계통도

```text
                         AC 220V
                            │
             ┌──────────────┴──────────────┐
             │                             │
             ▼                             ▼
 ┌──────────────────────┐       ┌──────────────────────┐
 │ 12V/5V 겸용 어댑터    │       │       12V SMPS       │
 │      (5V 설정)       │       │                      │
 └──────────┬───────────┘       └───────────┬──────────┘
            │                               │
           5V                              12V
            │                               │
            ▼                    ┌──────────┼──────────┐
 ┌──────────────────────┐         │          │          │
 │    Raspberry Pi      │         ▼          ▼          ▼
 │      전용 전원       │     ┌───────┐  ┌───────┐  ┌───────┐
 └──────────┬───────────┘     │L298N #1│ │L298N #2│ │L298N #3│
            │                 └───┬───┘  └───┬───┘  └───┬───┘
            │ USB                     │          │          │
            ▼                         │          │          │
 ┌──────────────────────┐             ▼          ▼          ▼
 │     Arduino Mega     │          M1, M2     M3, M4       M5
 │   5V 로직 전원       │
 └──────────────────────┘

                    12V SMPS
                       │
                       ▼
              ┌─────────────────┐
              │ U2D2 Power Hub  │
              │   (모터 계통)   │
              └─────────────────┘
```

> **※ Raspberry Pi 전원 계통과 12V 모터 전원 계통은 서로 독립되어 있다.**

---

## 3. Raspberry Pi 전원 계통

Raspberry Pi는 12V SMPS에서 전원을 공급받지 않는다.

별도의 **12V/5V 겸용 어댑터를 5V로 설정**하여 Raspberry Pi 전용 전원으로 사용한다.

```text
12V/5V 겸용 어댑터
       │
       │ 5V 설정
       ▼
┌─────────────────┐
│  Raspberry Pi   │
└─────────────────┘
```

---

## 4. Arduino 로직 전원

Arduino Mega는 Raspberry Pi와 USB로 연결되며, USB를 통해 **5V 로직 전원**을 공급받는다.

```text
┌─────────────────┐
│  Raspberry Pi   │
└────────┬────────┘
         │
         │ USB / 5V
         ▼
┌─────────────────┐
│  Arduino Mega   │
│  로직 전원 5V   │
└─────────────────┘
```

### Arduino 로직 전원과 모터 전원의 구분

Arduino Mega의 5V 전원은 **제어회로를 위한 로직 전원**이며, 리니어 모터를 직접 구동하기 위한 전원이 아니다.

```text
Arduino Mega
     │
     └── 5V → 제어회로(Logic Power)

12V SMPS
     │
     └── 12V → L298N → 리니어 모터(Motor Power)
```

---

## 5. 모터 구동 전원 계통

리니어 모터 5개는 12V SMPS에서 공급되는 전원을 L298N 모터 드라이버를 통해 구동한다.

```text
                         12V SMPS
                            │
              ┌─────────────┼─────────────┐
              │             │             │
              ▼             ▼             ▼
         ┌─────────┐   ┌─────────┐   ┌─────────┐
         │ L298N #1│   │ L298N #2│   │ L298N #3│
         └────┬────┘   └────┬────┘   └────┬────┘
              │             │             │
          ┌───┴───┐     ┌───┴───┐         │
          ▼       ▼     ▼       ▼         ▼
       Motor 1 Motor 2 Motor 3 Motor 4  Motor 5
```

### 모터 배치

| Motor Driver | Linear Motor     |
| ------------ | ---------------- |
| L298N #1     | Motor 1, Motor 2 |
| L298N #2     | Motor 3, Motor 4 |
| L298N #3     | Motor 5          |

---

## 6. U2D2 Power Hub 전원

U2D2 Power Hub는 12V SMPS의 모터 전원 계통에서 전원을 공급받는다.

```text
12V SMPS
    │
    ▼
┌─────────────────┐
│ U2D2 Power Hub  │
└─────────────────┘
```

---

## 7. 전원 구성 요약

| 구분                |         전압 | 공급원                   | 대상                       |
| ----------------- | ---------: | --------------------- | ------------------------ |
| Raspberry Pi 전원   |         5V | 12V/5V 겸용 어댑터 (5V 설정) | Raspberry Pi             |
| **Arduino 로직 전원** |     **5V** | **Raspberry Pi USB**  | **Arduino Mega (제어회로)**  |
| **모터 구동 전원**      | **12V DC** | **12V SMPS**          | **L298N ×3 → 리니어 모터 5개** |
| U2D2 전원           |     12V DC | 12V SMPS              | U2D2 Power Hub           |

## 8. 전원 계통 분리

본 시스템의 전원은 다음과 같이 구분된다.

```text
[제어 계통]

12V/5V 겸용 어댑터
        │
       5V
        │
        ▼
 Raspberry Pi
        │
       USB
        │
        ▼
 Arduino Mega
        │
     5V Logic
        │
   제어 회로 동작


[모터 구동 계통]

12V SMPS
    │
    ├──► L298N #1 ──► Motor 1, Motor 2
    │
    ├──► L298N #2 ──► Motor 3, Motor 4
    │
    ├──► L298N #3 ──► Motor 5
    │
    └──► U2D2 Power Hub
```

---

## 9. 주의사항

> **⚠️ 전원 분리 주의**

1. Arduino Mega의 **5V 로직 전원**과 리니어 모터의 **12V 구동 전원**은 서로 다른 용도로 사용한다.
2. 리니어 모터의 12V 구동 전원을 Arduino Mega의 5V 핀에 직접 연결하지 않는다.
3. 리니어 모터는 Arduino Mega에서 직접 구동하지 않고 **L298N 모터 드라이버를 통해 구동**한다.
4. Raspberry Pi는 별도의 5V 어댑터를 사용하며, 12V SMPS에서 직접 전원을 공급하지 않는다.
5. 본 시스템에서는 **Buck Converter를 사용하지 않는다.**
6. 실제 배선 시 전원공급기의 정격 전압 및 전류를 확인한 후 연결한다.

## 10. 전원 계통 최종 구조

```text
                    ┌─────────────────────┐
                    │      AC 220V        │
                    └──────────┬──────────┘
                               │
              ┌────────────────┴────────────────┐
              │                                 │
              ▼                                 ▼
     12V/5V 겸용 어댑터                       12V SMPS
          (5V 설정)                              │
              │                         ┌────────┼────────┐
              │                         │        │        │
             5V                         ▼        ▼        ▼
              │                       L298N    L298N    L298N
              ▼                         #1       #2       #3
       Raspberry Pi                     │        │        │
              │                         ▼        ▼        ▼
             USB                    M1, M2    M3, M4     M5
              │
              ▼
       Arduino Mega
       (5V Logic Power)

                                           │
                                           ▼
                                     U2D2 Power Hub
```

**전원 계통 구분**

* **제어 전원:** 5V → Raspberry Pi → USB → Arduino Mega
* **모터 구동 전원:** 12V → L298N ×3 → 리니어 모터 ×5
* **U2D2 전원:** 12V SMPS → U2D2 Power Hub
* **Buck Converter: 사용하지 않음**
