# 전원 계통도

## 1. 전체 전원 구성

스마트 시트 시스템은 **Raspberry Pi 제어 계통**과 **모터 구동 계통**을 독립적인 전원으로 구성한다.

```text
                         AC 220V
                            │
             ┌──────────────┴──────────────┐
             │                             │
             ▼                             ▼
   ┌────────────────────┐        ┌────────────────────┐
   │ 12V/5V 겸용 어댑터  │        │     12V SMPS       │
   │    (5V 설정)       │        │                    │
   └──────────┬─────────┘        └──────────┬─────────┘
              │ 5V                         │ 12V
              │                            │
              ▼                 ┌──────────┼──────────┐
   ┌────────────────────┐       │          │          │
   │   Raspberry Pi     │       ▼          ▼          ▼
   │    전용 전원       │   ┌───────┐  ┌───────┐  ┌───────┐
   └────────────────────┘   │L298N #1│ │L298N #2│ │L298N #3│
                             └───┬───┘  └───┬───┘  └───┬───┘
                                 │          │          │
                              Motor 1~2  Motor 3~4   Motor 5

                              12V SMPS
                                  │
                                  ▼
                          ┌─────────────────┐
                          │ U2D2 Power Hub  │
                          │   (모터 계통)   │
                          └─────────────────┘


       ┌──────────────────────────────────────────────┐
       │                                              │
       │   Raspberry Pi 전원 계통                     │
       │   12V/5V 어댑터 → 5V → Raspberry Pi          │
       │                                              │
       │   모터 전원 계통                              │
       │   12V SMPS → L298N ×3 + U2D2 Power Hub       │
       │                                              │
       │   ※ 두 전원 계통은 서로 독립                  │
       │   ※ Buck Converter 사용하지 않음              │
       └──────────────────────────────────────────────┘
```

## 2. Raspberry Pi 전원 계통

Raspberry Pi는 **12V SMPS에서 전원을 공급받지 않는다.**

별도의 12V/5V 겸용 어댑터를 **5V로 설정하여 Raspberry Pi 전용 전원**으로 사용한다.

```text
12V/5V 겸용 어댑터
       │
       │ 5V 설정
       ▼
Raspberry Pi
```

## 3. 모터 전원 계통

모터 구동부는 별도의 **12V SMPS**를 사용한다.

```text
12V SMPS
   │
   ├──────────────► L298N #1 ───► Linear Motor 1
   │                       └────► Linear Motor 2
   │
   ├──────────────► L298N #2 ───► Linear Motor 3
   │                       └────► Linear Motor 4
   │
   └──────────────► L298N #3 ───► Linear Motor 5
   │
   └──────────────► U2D2 Power Hub
```

## 4. 전원 계통 분리

| 전원 계통 | 전원 장치         |  출력 | 공급 대상           |
| ----- | ------------- | --: | --------------- |
| 제어 계통 | 12V/5V 겸용 어댑터 |  5V | Raspberry Pi    |
| 모터 계통 | 12V SMPS      | 12V | L298N ×3        |
| 모터 계통 | 12V SMPS      | 12V | U2D2 Power Hub  |
| 모터 구동 | L298N         | 12V | Linear Motor ×5 |

> **중요:** Raspberry Pi 전원 계통과 모터 전원 계통은 서로 독립되어 있다.

> **주의:** 실제 배선에 Buck Converter가 사용되지 않으므로 전원 계통도에서도 Buck Converter를 표시하지 않는다.

## 5. 전원 구성 요약

```text
[제어 전원]
12V/5V 겸용 어댑터
        │
       5V
        │
        ▼
 Raspberry Pi


[모터 전원]
   12V SMPS
      │
      ├──► L298N #1 ──► Motor 1, 2
      ├──► L298N #2 ──► Motor 3, 4
      ├──► L298N #3 ──► Motor 5
      │
      └──► U2D2 Power Hub
```

### 전원 계통의 핵심

* **Raspberry Pi:** 별도 12V/5V 겸용 어댑터의 **5V 출력** 사용
* **L298N ×3:** 12V SMPS 사용
* **U2D2 Power Hub:** 12V SMPS 계통 사용
* **Linear Motor ×5:** L298N을 통해 12V 모터 계통에서 구동
* **Buck Converter:** 사용하지 않음
* **Raspberry Pi 전원과 모터 전원:** 독립된 전원 계통
