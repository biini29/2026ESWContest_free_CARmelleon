# 스마트 시트 전원 계통도 (Power System)

스마트 시트 시스템의 전원 공급 구조를 정리한 문서입니다.

본 시스템은 **Raspberry Pi 제어 계통(5V)**과 **모터 구동 계통(12V)**을 분리하여 구성합니다.

---

---

## 2. Raspberry Pi 전원

```text
12V / 5V 어댑터
       │
       │ 5V 설정
       ▼
Raspberry Pi 4
```

* Raspberry Pi 4 전용 전원입니다.
* 12V / 5V 어댑터를 **5V로 설정하여 사용**합니다.
* Raspberry Pi에 12V를 직접 공급하지 않습니다.
* 본 구성에서는 별도의 Buck Converter를 사용하지 않습니다.

---

## 3. Arduino 로직 전원

```text
Raspberry Pi 4
      │
      │ USB
      ▼
Arduino Mega 2560
      │
      └── Arduino 로직 전원
```

* Raspberry Pi와 Arduino Mega는 USB로 연결합니다.
* USB를 통해 Arduino의 **로직 전원과 Serial 통신**을 공급합니다.
* Arduino의 로직 전원과 모터 구동 전원은 분리합니다.

---

## 4. 리니어 모터 전원

12V SMPS에서 L298N 3개로 전원을 분배합니다.

```text
                         12V SMPS
                            │
              ┌─────────────┼─────────────┐
              │             │             │
             12V           12V           12V
              │             │             │
              ▼             ▼             ▼
          L298N #1       L298N #2       L298N #3
              │             │             │
           ┌──┴──┐       ┌──┴──┐          │
           ▼     ▼       ▼     ▼          ▼
          M1     M2      M3    M4         M5
```

### 모터 구성

| 드라이버     | 모터                  |
| -------- | ------------------- |
| L298N #1 | Linear Motor #1, #2 |
| L298N #2 | Linear Motor #3, #4 |
| L298N #3 | Linear Motor #5     |

* 리니어 모터 구동 전원은 12V SMPS를 사용합니다.
* L298N은 Arduino Mega의 제어 신호를 받아 모터를 구동합니다.

---

## 5. DYNAMIXEL 전원

DYNAMIXEL은 **U2D2 Power Hub를 통해 전원과 통신을 공급**받습니다.

```text
12V SMPS
    │
    │ 12V
    ▼
U2D2 Power Hub
    │
    ├────────── 3핀 ──────────► XL430-W250-T #1
    │
    └────────── 3핀 ──────────► XL430-W250-T #2
```

### DYNAMIXEL 구성

| 장치           | 수량 | 연결                 |
| ------------ | -: | ------------------ |
| XL430-W250-T |  1 | Power Hub → 3핀 케이블 |
| XL430-W250-T |  1 | Power Hub → 3핀 케이블 |

두 DYNAMIXEL은 서로 데이지체인으로 연결하지 않고 **U2D2 Power Hub에서 각각 직접 연결**합니다.

---

## 6. U2D2 통신 및 전원 구조

U2D2는 Raspberry Pi와 USB로 연결하고, U2D2와 U2D2 Power Hub는 3핀 케이블로 연결합니다.

```text
                         Raspberry Pi 4
                              │
                              │ USB
                              ▼
                           ┌──────┐
                           │ U2D2 │
                           └───┬──┘
                               │
                              3핀
                               │
                               ▼
                      ┌─────────────────┐
                      │ U2D2 Power Hub  │
                      └───────┬─────────┘
                              │
                    ┌─────────┴─────────┐
                   3핀                  3핀
                    │                    │
                    ▼                    ▼
             XL430-W250-T #1      XL430-W250-T #2
```

### 연결 관계

```text
Raspberry Pi
     │
     │ USB
     ▼
   U2D2
     │
     │ 3핀 케이블
     ▼
U2D2 Power Hub
     ├──── 3핀 ────► XL430 #1
     │
     └──── 3핀 ────► XL430 #2
```

## 8. 전원 계통 요약표

| 전원 공급원           | 공급 대상             |  전압 | 용도            |
| ---------------- | ----------------- | --: | ------------- |
| 12V / 5V 어댑터     | Raspberry Pi 4    |  5V | 메인 컨트롤러 전원    |
| Raspberry Pi USB | Arduino Mega 2560 |  5V | Arduino 로직 전원 |
| 12V SMPS         | L298N #1          | 12V | M1 / M2 구동    |
| 12V SMPS         | L298N #2          | 12V | M3 / M4 구동    |
| 12V SMPS         | L298N #3          | 12V | M5 구동         |
| 12V SMPS         | U2D2 Power Hub    | 12V | DYNAMIXEL 전원  |
| U2D2 Power Hub   | XL430-W250-T #1   | 12V | DYNAMIXEL 구동  |
| U2D2 Power Hub   | XL430-W250-T #2   | 12V | DYNAMIXEL 구동  |

   ├──► L298N #2 ──► Linear Motor #3, #4
   │

## 10. 전원 구성 주의사항

1. Raspberry Pi에는 **12V를 직접 연결하지 않습니다.**
2. Raspberry Pi는 12V / 5V 어댑터를 **5V로 설정하여 사용**합니다.
3. 별도의 Buck Converter는 사용하지 않습니다.
4. Arduino Mega는 Raspberry Pi USB를 통한 **로직 전원**을 사용합니다.
5. 리니어 모터는 **12V SMPS → L298N**을 통해 구동합니다.
6. DYNAMIXEL은 **12V SMPS → U2D2 Power Hub**를 통해 구동합니다.
7. U2D2와 Power Hub는 **3핀 케이블**로 연결합니다.
8. Power Hub와 XL430-W250-T 2개는 각각 **별도의 3핀 케이블**로 연결합니다.
9. Raspberry Pi 전원과 12V 모터 전원은 서로 다른 전원 계통으로 구성합니다.
10. 전원 연결 전 반드시 각 장치의 전압 사양과 극성을 확인합니다.
