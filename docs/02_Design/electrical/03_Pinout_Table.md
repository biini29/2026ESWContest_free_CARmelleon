# Smart Seat System Pin Map

> Arduino Mega, Raspberry Pi, L298N 및 5개 등받이 모터의 전기적 연결과 핀 매핑을 정리한 문서입니다.
>
> 키패드, LCD, 초음파 센서, DYNAMIXEL 등의 핀맵은 별도 자료 확인 후 추가합니다.

---

# 1. 전체 시스템 구성

```text
                    Raspberry Pi
                         │
                         │ USB Serial
                         ▼
                   Arduino Mega
                         │
          ┌──────────────┼──────────────┐
          │              │              │
          ▼              ▼              ▼
       L298N #1       L298N #2       L298N #3
       모터 1, 2      모터 3, 4        모터 5
          │              │              │
          └──────────────┼──────────────┘
                         │
                  등받이 모터 5개
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
       150 mm         320 mm         490 mm
          │              │              │
          └──────────────┼──────────────┘
                         │
                   660 mm / 830 mm
```

## 시스템 역할

* **Raspberry Pi**: ROS2 기반 상위 제어 및 모터 명령 생성
* **Arduino Mega**: 모터 제어 명령 수신 및 L298N 제어
* **L298N × 3**: 5개 모터의 구동 및 방향 제어
* **모터 × 5**: 등받이의 서로 다른 위치에 배치
* **12V SMPS**: 모터 구동 전원 공급

# 6. 모터별 최종 핀맵

> **중요:** Motor 번호는 Arduino/L298N에서 사용하는 물리 모터 번호입니다.
>
> 실제 등받이 위치는 조립 과정에서 Motor 1과 Motor 2가 서로 뒤바뀌었기 때문에 소프트웨어에서 `MOTOR_MAP`으로 보정합니다.

| Arduino 모터 | L298N  | EN | IN1 | IN2 | 담당 위치      |
| ---------- | ------ | -: | --: | --: | ---------- |
| Motor 1    | #1 A채널 | D2 | D22 | D23 | **320 mm** |
| Motor 2    | #1 B채널 | D3 | D24 | D25 | **150 mm** |
| Motor 3    | #2 A채널 | D4 | D26 | D27 | **490 mm** |
| Motor 4    | #2 B채널 | D5 | D28 | D29 | **660 mm** |
| Motor 5    | #3 A채널 | D6 | D30 | D31 | **830 mm** |

# 7. 등받이 모터 배치

5개의 모터는 각각 특정 기능에 고정된 모터가 아니라, **등받이의 서로 다른 위치를 담당하는 구조**입니다.

```text
                 등받이
                   │
                   │
     150 mm   ────●──── Motor 2
                   │
     320 mm   ────●──── Motor 1
                   │
     490 mm   ────●──── Motor 3
                   │
     660 mm   ────●──── Motor 4
                   │
     830 mm   ────●──── Motor 5
                   │
```

각 모터의 위치는 고정된 기능을 의미하지 않습니다.

예를 들어:

* 특정 사용자의 허리 위치 → 해당 위치 주변 모터에 더 큰 압력/구동
* 머리 위치 → 상부 모터에 더 큰 구동
* 사용자 체형 → 가우시안 곡선 계산을 통해 5개 모터의 목표값 결정

즉, **5개 모터 전체가 등받이 형상 조절에 참여**합니다.

# 8. 소프트웨어 모터 매핑

실제 조립 과정에서 Motor 1과 Motor 2의 위치가 서로 뒤바뀌었기 때문에 소프트웨어에서 이를 보정합니다.

```python
MOTOR_MAP = [2, 1, 3, 4, 5]
```

### 매핑

| 제어상 위치 | 실제 물리 모터 |
| ------ | -------- |
| 150 mm | Motor 2  |
| 320 mm | Motor 1  |
| 490 mm | Motor 3  |
| 660 mm | Motor 4  |
| 830 mm | Motor 5  |

따라서 **배선을 다시 변경하지 않고 소프트웨어 매핑으로 물리적 스왑을 보정**합니다.

# 9. L298N → 모터 연결

## L298N #1

```text
L298N #1
   │
   ├── OUT1 / OUT2 ──→ Motor 1
   │
   └── OUT3 / OUT4 ──→ Motor 2
```

## L298N #2

```text
L298N #2
   │
   ├── OUT1 / OUT2 ──→ Motor 3
   │
   └── OUT3 / OUT4 ──→ Motor 4
```

## L298N #3

```text
L298N #3
   │
   └── OUT1 / OUT2 ──→ Motor 5

OUT3 / OUT4 → 사용하지 않음
```

# 10. 전원 연결

모터 구동 전원은 **12V SMPS**를 사용합니다.

```text
                    12V SMPS
                   ┌─────────┐
                   │ +V COM  │
                   └─┬────┬──┘
                     │    │
          ┌──────────┼────┼──────────┐
          │          │    │          │
          ▼          ▼    ▼          ▼
       L298N #1   L298N #2       L298N #3
```

| 출발지        | 목적지            | 역할               |
| ---------- | -------------- | ---------------- |
| SMPS `+V`  | L298N #1 전원 입력 | Motor 1, 2 구동 전원 |
| SMPS `COM` | L298N #1 GND   | 전원 GND           |
| SMPS `+V`  | L298N #2 전원 입력 | Motor 3, 4 구동 전원 |
| SMPS `COM` | L298N #2 GND   | 전원 GND           |
| SMPS `+V`  | L298N #3 전원 입력 | Motor 5 구동 전원    |
| SMPS `COM` | L298N #3 GND   | 전원 GND           |

> **주의:** 모터 구동 전원은 Arduino Mega의 5V 핀에서 공급하지 않습니다.

---

# 11. GND 공통 연결

Arduino와 L298N의 신호 기준을 맞추기 위해 GND를 공통으로 연결합니다.

```text
Arduino Mega GND
       │
       ├────────→ L298N #1 GND
       │
       ├────────→ L298N #2 GND
       │
       └────────→ L298N #3 GND
```

그리고 모터 전원은 별도의 12V SMPS에서 공급합니다.

```text
Arduino GND ─────┐
                 ├── 공통 GND 기준
L298N #1 GND ────┤
L298N #2 GND ────┤
L298N #3 GND ────┘

12V SMPS COM ────→ L298N 전원 GND
```
