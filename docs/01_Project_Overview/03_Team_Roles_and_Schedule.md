
# 팀원 역할 및 일정

## 1. 팀 구성

**팀명**: CAR멜레온 | 동국대학교 기계로봇에너지공학과

| 이름 | 역할 |
|---|---|
| **민설빈** (팀장) | ROS 2 시스템 통합, 제어 로직, 하드웨어 브릿지, 캘리브레이션, Size Korea 회귀분석 |
| **김재경** | 전체 설계 및 핀 연결, 기존 노드들을 launch 파일로 통합, GitHub 저장소 정리 |
| **차보겸** | 전체 설계(주도) 및 하드웨어 연결, 어셈블(통합) 파일 작업, GitHub 저장소 정리 |

## 2. 역할 분담 개요

- **하드웨어/메커니즘 설계**: 시트 구조, 리니어 액추에이터 배치, 다이나믹셀 벨트 릴 구조, 헤드레스트 자리 초음파센서 브라켓 CAD (주로 차보겸, 전체 설계 참여)
- **회로/전원 설계**: SMPS 배선, Arduino 핀맵, L298N 모터드라이버 회로 (김재경·차보겸 공동)
- **임베디드/ROS 소프트웨어**: 아두이노 펌웨어, ROS 2 노드, 통신 프로토콜, 캘리브레이션 (민설빈 중심)
