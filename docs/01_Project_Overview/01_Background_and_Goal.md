
# 개발 배경 및 목표

## 1. 기획 배경

자동차 시트는 대부분 성인 평균 체형 기준으로 고정 설계된다. 자동차 업계에서는 시트 설계 시 미국 성인 남성 50번째 백분위(AM50, 175cm·78kg 표준 더미) 모델을 하중 조건으로 삼는 것이 일반적이다.

그러나 실제 차량에는 카시트를 졸업한 아이, 임산부, 손님 등 체형이 전혀 다른 여러 사람이 번갈아 탑승한다. 체형에 맞지 않는 시트는 잘못된 착석 자세를 유발하고, 특히 안전벨트가 몸에 맞지 않는 위치를 지나가면 충돌 시 부상 위험이 커진다. 미국 교통안전공단의 2011년 조사에 따르면, 동일한 사고 조건에서도 여성 운전자의 부상 확률이 남성보다 47% 높게 나타났는데, 이는 안전장치가 표준체형(남성) 기준으로 설계된 것이 한 원인으로 지목된다.

## 2. 핵심 타겟

- 가족형 RV/SUV 차량 사용자 (다자녀·다세대 가족)
- 임산부
- 단기 카셰어링/렌트 게스트

## 3. 개발 목표

Size Korea 8차 인체치수조사 데이터(유효표본 5,092명)를 기반으로 개인별 요추·어깨 위치를 계산하고, 이를 리니어 액추에이터와 다이나믹셀 서보모터로 실시간 구현하여 **"누가 타든 안전한 자세"를 자동으로 완성**하는 것을 목표로 한다.

- 안전성 개선: 표준체형 기준 설계의 사각지대(여성, 아동, 임산부, 다양한 체형)를 데이터 기반 개인화로 완화
- 편의성 개선: 가족 구성원이 시트 하나를 공유하며, 매번 수동으로 재조정하지 않고 프로필 버튼 하나로 즉시 전환

## 4. 핵심 사용 시나리오

### 시나리오 1 — 가족 모드
저장된 가족 프로필(A/B/C, 이름·키·임산부여부)을 키패드에서 선택하면 즉시 해당 체형에 맞춰 등받이 곡선과 안전벨트 높이가 변형된다.

### 시나리오 2 — 게스트 모드
가족 구성원이 아닌 손님이 탑승할 경우, 두 가지 방법으로 대응한다:
- **수동 입력**: 키패드로 키(cm)를 직접 입력
- **자동 측정**: 천장(헤드레스트 자리)에 장착된 초음파 센서로 3초 롱프레스 시 자동으로 신장을 추정하여 적용

### 시나리오 3 — 임산부 모드
일반 모드와 달리, 요추 지지 곡선을 낮고 부드럽게 조정하고(과도한 요추 전만·장골동맥 압박 방지), 안전벨트는 어깨가 아닌 골반 위치를 지나가도록 가이딩하여 복부 압박을 방지한다.

## 5. 설계 적용 범위

키 130~185cm (185cm은 한국 성인 남성 99백분위수 기준). 이 범위를 벗어나는 경우 시스템은 동작을 적용하지 않고 적용 가능 범위를 안내한다.
